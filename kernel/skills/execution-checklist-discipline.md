# Execution Checklist Discipline

Use when Aldebaran runs verification.

- Run exactly the commands named by the plan or handoff, in order.
- Do not broaden, retry, substitute, fix, or invent commands.
- At the first required Done-when failure, report FAIL immediately and stop.
- If a command or instruction is ambiguous, ask through the relay before acting.
- Classify only observed evidence: command, exit, output shape, and files present.
