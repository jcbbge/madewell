# Ground — the human door

Ground is the stop on **ideate** and **plan**. It is part of Made Well, not a skill you add
to a repo and not a slash command in a harness.

You already have it when Made Well is installed: `.madewell/ground/`. Re-sync updates the
protocol; this project's **roots** (what to look at) are seeded once and left alone.

## What you will see

Before anything is designed, the agent lays the existing decisions on the table:

1. Everything already written that bears on the work (docs, decisions, pieces on the rack).
2. What actually exists in the material (code, artifacts) — path and line, this sitting.
3. The gap between those two. Then it **stops**. Planning is the next act.

It does not branch, edit, or commit. A claim without a lookup this sitting is not a fact.

## Layout

| Path | Who owns it | What |
|---|---|---|
| `ground/README.md` (this file) | kernel (re-sync) | human door |
| `ground/PROTOCOL.md` | kernel (re-sync) | how grounding is done — the stop |
| `ground/PICTURE.md` | kernel (re-sync) | what a finished grounding looks like |

A trade may name extra roots in its own files. They add to `ROOTS.md`; they do not replace it.
