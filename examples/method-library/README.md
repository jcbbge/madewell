## Exercise an explicit source selection

In a disposable fixture, place `discovery.json` and `delivery.json` at its root. Copy only the corresponding proposed package directories under `skills/`, with complete selected supporting files and the applicable upstream license notice. This is test material, not an installed or canonical fork. For example, `skills/madewell-classifying/SKILL.md` is relative to the directory containing `discovery.json`.

The non-maker verifier invokes the actual source or packed executable with an absolute fixture root:

```sh
mw cartridges --inspect --root /absolute/disposable-fixture --config discovery.json --component /discovery
mw cartridges --inspect --root /absolute/disposable-fixture --config delivery.json --component /delivery
```

`discovery.json` replaces seven leaf methods; `delivery.json` replaces four. Unmentioned branches retain their existing defaults. A missing explicit package is a visible error, never a fallback. Input/output strings are the current resolver's nominal compatibility declarations; they are not a JSON Schema validator or proof that a method fulfilled its semantics. The `confirm` occurrence retains its existing output contract even though its historical internal job name is `discover`.

Inspection returns selected exact instruction text, package identities and manifests. It does not run a method, persist a handoff, select candidates, execute scripts, authorize paid effort, or certify any scenario. Durable use is a separate explicit mutation: `capture_work` accepts `component:"/discovery",config:"discovery.json"` (or `/delivery` and `delivery.json`) alongside `requestId`, `actor` and exact `source`. Prepare/record retain selected bytes and contributions without invoking a performer. Discovery confirmation creates candidates; separate preview/promotion selects exactly explicit IDs as external work, never executing them. See the [portable-work API contract](../../README.md#explicit-portable-work-handoffs). Ordinary skills can be read and applied independently by an authorized chosen assistant. Authored deeper recipes do not create a managed entitlement service; required free correctness/evidence remains unconditional.
