# Structured work demonstration

`npm run demo -- init` captures two independent fictional text tasks with the four neutral execution-2 nodes and explicit independent acceptance. `run` selects these examples; `--item` selects an exact root. `discover --source-file file` preserves raw input. `serve` drives only browser-selected roots and linked work during the foreground server lifetime. `status` reads saved results. No service, registry, repository or delivery command is created. Model calls require configured/authenticated prescriptions. A fixture result is not evidence that a real workshop occurred or any message was sent.
