# Provisioned exchanges and NQ

Every agent-to-agent handoff, including a return, clarification, failure or replacement, is one NQ exchange. NQ establishes understanding; it is neither result acceptance nor permission to summon more agents.

## Sender responsibility

Identify actual parties, responsibilities and reply route; link the work and prior exchange. Supply purpose/outcome, exact scoped sources, settled decisions, prior answers, tools and access actually available, action/decision boundaries, expected result and evidence, and contingencies. Proportion the handoff to the recipient: a researcher needs an open investigation, an implementer an actionable fixed brief, a verifier the actual candidate and available proof inputs. Volume is not completeness. Do not forward an undifferentiated transcript as a substitute for preparation.

## Receiver responsibility

State the understood purpose and scope. Resolve “What is unclear? What is ambiguous? Do I have everything needed?” from the supplied record. If clear, proceed without manufacturing questions or three rounds. If a material input is missing or contradictory, identify the smallest question, its source and the action it blocks. Distinguish a missing fact from a delegated choice; inspect accessible sources and settle delegated choices rather than interviewing the human.

Reuse a settled answer only within its authority and scope. Retain the original question, answer, author, source and any paraphrase/alias used for reuse. A claimed duplicate with no recorded match is not an answer. Changed circumstances may require a new question; explain the change instead of erasing the earlier resolution.

The sender answers from the fixed brief and source, without silently changing the assignment. The receiver confirms readiness or what remains unresolved. A needed scope change is explicit, preserves prior attempts, and is accepted by its actual authority; it is not disguised as clarification.

## Count and hold

One answered question turn increments the exchange count once, regardless of transport retries. Preserve it across successor/replacement handoffs and reused question aliases. A clear initial assignment uses zero answered turns. After the third answered turn, allow confirmation; if questions remain, hold the affected work for a specification/scope defect and alert the responsible human once through the established channel. Name sender, receiver, work, unresolved questions and blocked action. No fourth agent-only round, agent swap, renamed question or new thread resets the limit. Other independent work need not stop.

Required authority is a separate boundary: do not wait three turns to avoid an immediate safety stop. Human clarification does not itself perform the work or prove acceptance; the receiver still confirms understanding. Record hold, alert outcome, answer and release separately when supported. If alert delivery is uncertain, inspect its receipt before repeating it.

Use the existing work record, not a parallel task board. Preserve exact return/refusal, questions, answers, understanding, count, owners and remaining gap before the next call. Without durable facilities, return this information honestly; text cannot guarantee crash recovery.

## Failure return

Send the attempted action, actual error/evidence, affected condition, exact partial result, uncertainty about effects and recommended safe next action. A failed check is evidence needing attribution, not permission for its verifier to repair the artifact or weaken the condition. Use the configured failure owner to determine whether plan/implementation, check design, an external prerequisite, or unavailable evidence needs attention. Leave the cause unknown when observations do not settle it.

**Example:** A recipient already has the approved data cutoff answer. Reuse that answer with its identity; do not ask it again because a new agent card arrived. If the supplied dataset predates that cutoff, ask about the dataset mismatch, not the settled cutoff choice.
