# Ground — the picture (what "done" looks like)

A grounding is complete when all of the following exist **in this sitting**. Missing a
section is an incomplete ground, not a shorter one. Create nothing on disk unless the
person asked for a written picture; speaking it is enough. If you write it, match this
shape.

---

## 0. Pre-flight

- Every path in `.madewell/ground/ROOTS.md` was checked for existence this sitting.
- Nouns pulled from the task: the search terms used below.
- Any named path that does not exist is listed as **`NO EXISTING IMPLEMENTATION — net new`**.

---

## 1. Corpus

A table:

| path | what it is | relevance (this task) | one line |

Then:

**LOCKED DECISIONS** — each one `file:line` plus the decision in one sentence.

**OPEN QUESTIONS / CONTRADICTIONS** — each one `file:line` or `UNKNOWN`.

**Corpus synthesis** — short. What the written record says this must be.

---

## 2. Material

For each relevant surface:

| path | lines | verdict (`BUILT` / `PARTIAL` / `NET-NEW`) | one line |
| gap | what exists vs what the task still needs |
| contradiction | any material that already fights the spec |

Empty search → **`NO EXISTING IMPLEMENTATION — net new`**, never a blank.

---

## 3. The gap

- What the record says it must be vs what exists today.
- Locked decisions that bind the work.
- Open decisions: *lead-owned* (decide now) vs *external* (someone else).
- **Recommended next move**, with file:line anchors.

Ground **stops here**. The floor (`Making` / `Not making` / `Done when` / `Waits on`) is
plan, after.
