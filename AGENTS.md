# Made Well

Read [`FOUNDATION.md`](FOUNDATION.md) before changing this application; it is operator law. The operator's standing authority (ruling 20) is to apply the three-question rubric: a choice that advances at least two of developer, user and agentic experience is implemented, tested and reflected in the foundation and supporting instructions. Do not ask the operator to settle routine design choices or preserve stale rules as blockers.

- **Preserve the grammar of work.** Capture input → generate tasks → complete tasks. Every task owes ideation, planning, implementation and verification; complexity changes depth, not those obligations. Software is one domain of this grammar. Arbitrary function-pack capability does not establish that the prescribed grammar was fulfilled. See the operator clarification and opt-in branch experiment in FOUNDATION.md.
- **Every node is an input/output cartridge.** Function packs support zero/one/many agent or trusted command nodes and nested groups, without Git. Preserve accepted/attempted nodes across explicit boundary updates. Record configuration, calls, outputs and errors; completion never invents verification or shipping. See the README's function-pack contract.
- **Every agent-to-agent interaction is an NQ exchange.** No hand-off skips intake; a new card is a new agent.
- **Profiles only.** Never give agents personal names (ideator, ideation peer, planner, test architect, implementer, arbiter, dispatcher, operator, operator's agent).
- **The operator's agent stays outside the glass.** It reads every record, trace and metric through Made Well's read surface and narrates; it never moves the work (FOUNDATION, ruling 16).
- **Compact context, explicit operator input.** `mw context <id>` and `/api/v1/items/<id>` share one projection: intent, position, revision, bounded conversation and evidence links, with next-input owner/authority. Keep legacy capture intact. Browser submissions/answers are the operator's authorized surface, not observer authority; route answers through the engine and commit transitions plus request receipts atomically. Preserve exact text, restart-safe retries, stale-state rejection, Origin/CSRF/body bounds and recoverable drafts. OpenAPI describes operations; OTLP export describes only saved finished evidence, never invented spans or inaccessible tool streams.
- **The work item is the durable object.** Save every transition to the store before the next call. Recovery is redriving the saved state; there is no other recovery path.
- **Ground, Rumen and next-step preparation are mandatory.** Every phase grounds its result in actual material, accounts for its applicable rules and prepares each configured consumer on the same durable task. Agents are disposable tools. The console refuses incomplete preparation, preserves blocked partials, rechecks required material, and keeps private makers isolated. Follow the [organ contract](dossiers/2026-10-31-ground-rumen.md); a declaration or fingerprint is not semantic proof or an executed gate.
- **Drive the established process.** The operator has already proven the complete pipeline through manual use. Remove manual context transfer: browser raw input starts configured discovery, task selection queues delivery, and saved outputs feed subsequent functions. The demo's foreground driver resumes only explicitly selected roots and their linked work; unrelated historical examples remain untouched. Do not install an always-on service as part of this wiring.
- **One trace, three lenses.** B2 stores live invocation/output/tool/heartbeat/signal evidence in the existing events, alongside returned calls. UX, DX and AX are read-only projections (`mw trace`, `/api/trace/<id>`), never separate state or schedulers. Preserve interrupted fragments, existing exports/replay and split-track isolation. Rich evidence and a minimal live display (`mw ui`) are required; optional renderers fail open. Unknown metrics and inaccessible internals are explicitly unavailable. Signals never automatically interrupt, retry, repair or steer work.
- **Nontechnical first.** Follow [DESIGN.md](DESIGN.md) for the work display: plain-language progress by default, technical evidence on demand, Plex Sans prose and Plex Mono system messages, with spacing derived from the primary line height. Inspect rendered states and keyboard interaction; never replace evidence with decorative status.
- **Answer once, reuse thereafter.** Give each handoff its relevant durable questions and answers. Send each distinct answer once, retaining aliases and using references rather than nested copies. Resolve repeats from the record, including rewordings linked to saved answer ids; never ask the operator to answer them again. Keep implementation and test-design exchanges independent. Tool-enabled Codex calls read the complete packet from its per-call file; no-tool intake stays inline and transport never changes access or acceptance.
- **The triple gate always runs.** Resolve context → repository intent → the [three-legged rubric](dossiers/2026-10-24-three-legged-rubric.md). Judge DX, UX and AX through their 3×3 matrices; record gains, costs, rationale and hit/miss. Three hits → build with conviction; two → proceed; fewer → reshape/stop; zero → do not build. Implementation and test-writing execute fixed briefs, never improvise. Three answered NQ turns with questions open holds for a spec defect, even in full autonomy.
- **Optional decision help only.** The [decision-model cartridge](dossiers/2026-10-24-decision-model-cartridge.md) is a prescriptions-controlled advisory seam, not another worker stage or authority. No inference provider is wired; missing, disabled or faulty cartridges use the in-process rubric. Do not add cost/token machinery or the deferred structured-hold UX.
- **A usage limit never reaches the operator.** Swap cards; wait for the earliest reset when every account is out.
- **Built for agents first.** Every command prints JSON. Every failure is a `MadeWellError` with `code`, `message`, `context` holding the facts needed to act, an optional `cause`, and `next` commands. Never throw a bare `Error` to the caller.
- **TypeScript + Effect.** Services are `Context.Service` classes provided as layers (`Store`, `Worker`). Engine steps are `Effect.fn('mw.<name>')`, so each is a traced span. Time comes from `Clock`, so `TestClock` drives tests. Node runs the `.ts` sources directly; keep syntax erasable (no enums, namespaces or parameter properties).
- **Tests.** Assert observable results through the engine or the CLI, with a scripted worker. Build with `npm run bundle` before CLI checks, then run affected test files/name selections and relevant `npm run typecheck`; do not require a whole-suite run for each change. Makers do not author or run their own acceptance checks; independent verification owns them.
- Never commit without an explicit request.

- **Portable grammar.** Installed `builtin:grammar` selects `made-well-autonomy-lab` version `1.3`; the alias does not rename the pack. Use the shared resolver for CLI init/cartridges/discover/start and browser submissions. Persist symbolic built-ins and absolute file selections; pin complete packs on new items and preserve historical/legacy item inspection. Omitted init selection preserves configuration; init `default` removes it. Preserve default/file behavior and function-pack-only live-update restrictions.
- **Historical exports.** Always compose `artifacts/history.json` (`instruction`, `entries`) from both maker roles through the shared descriptor decoder, retaining empty/corrupt-only diagnostics and repeated events. Available hashes retrieve exact `artifacts/<sha256>.patch` bytes relative to the export root; retain legacy patch/conditional manifest behavior even when history says unavailable. This operator index grants no worker or continuation authority. Local transport recipes, independent candidate checks and later plant activation have separate evidence owners; claim no vendor interchangeability or measured speedup.
