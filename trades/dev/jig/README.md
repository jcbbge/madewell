# Software trade — compiled conventions

Diet for the kernel Jig (`.madewell/jig/`). A project that loads this trade honors these;
`.madewell/jig/conventions/` is where *this repo* compiles its own.

| File | What |
|---|---|
| `conventions/frontend.json` | tokens, motion, shell names |
| `conventions/schema.json` | keys, money-as-cents, enums — **mined from Arc**; other software hosts re-feed |
| `conventions/testing.json` | no-mocks, allowlist shrinks, real-db-or-pure |
| `registry.arc.json` | Arc's wired-jig map as of that lab install — bind detectors to *this* host |

Shape: `jig/CONTRACT.md` in the kernel. Tiers: fences, rubrics, signs, names.
