# Pillar — Message

*The claim and its proof.*

## Principles

1. **Every claim carries a source or a mark.** Sourced, or explicitly marked unsourced. There
   is no third state, and prose confidence is not evidence.
2. **The strongest objection goes in the room.** Name it before the reader does. It is the
   cheapest credibility available.
3. **Specific beats superlative.** "Cuts onboarding from three weeks to four days" outperforms
   "dramatically faster", and it can be checked.
4. **One idea per asset.** An asset that argues three things argues none.

## Protocol

1. Write the claim in one sentence.
2. Name its source. Data, a customer's words, or a demonstrable fact. **No source → mark it
   `UNSOURCED` and it may not ship.**
3. Write the strongest objection. Steel-man it — the version a smart sceptic would make.
4. Answer it, or change the claim.
5. Rewrite using the audience's captured vocabulary, not the company's.
6. Run `skills/message-test.md`.

## Definition of done

- One claim, one sentence.
- A named source, or an explicit `UNSOURCED` mark and a decision to cut.
- The strongest objection is written down and answered in the asset itself.
- No word in it that the audience would not use.
