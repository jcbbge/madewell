# Pillar — Measurement

*Whether it moved anything.*

## Principles

1. **Baseline before launch, or there is no measurement.** After the fact, everything looks
   like it worked.
2. **A metric that cannot fall is not a metric.** Impressions go up. Name something that could
   have gone the wrong way.
3. **Name the instrument, not just the number.** "Conversion up 12%" measured how, over what,
   compared to what.
4. **Decide the decision in advance.** What will you do if it works, and if it does not? If
   the answer is the same either way, do not measure — just ship.

## Protocol

1. Write the number **before** launch, with the date it was taken.
2. Name one metric that could move the wrong way.
3. Name the instrument and the window.
4. Write the decision rule: *if above X we do A, if below we do B.*
5. After the window, record what happened — including nothing, which is a result.
6. Feed the finding back onto the rack. A campaign that taught you something and produced no
   lift is not a failure; a campaign that taught you nothing is.

## Definition of done

- A dated pre-launch baseline exists.
- A falsifiable metric is named.
- A decision rule was written before the result was known.
- The outcome is recorded, including null results.
